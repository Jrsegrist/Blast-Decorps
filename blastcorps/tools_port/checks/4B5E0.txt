# 4B5E0 (matched IDO C): block_spawn_all hands coll_add_dyn_tris registers it never sets
# (v0, t6, t9 and its caller's s1); the NM build passes them as arguments (see
# conventions.txt). These checks follow coll_add_dyn_tris down to lvl_build_coll_tri and compare
# the triangle records it builds at gDynTris.
# Stream at a0: s16 n1, n1 x 8 bytes (s16 x, y, z, model), s16 n2, then n2 records
# (s16 x, y, z, u8 model, u8 n, s16 flag, n x 0x16-byte items).
# (Before the fix, the NM build kept the asm coll_add_dyn_tris, which jal'd the C
# lvl_build_coll_tri with the asm register convention: the followed checks fault there.)

# (A stubbed coll_add_dyn_tris can't show its register inputs here: eqcheck reads an IDO
# caller's stub arguments from the C slots. Its records show them: byte 0x50 = v0,
# 0x57 = t6, 0x4F = t9, 0x58 = s1, all followed.)
# one record without items, then one with 0, 1 or 3
block_spawn_all: -n 200 --ret void --arg a0=ptr:0x80 --arg a1=rel:a0+0x80 --arg s1=int \
    --mem @a0:2=1 --mem @a0+8:2=choice:0,1,2 --mem @a0+10:2=choice:1,2 --mem @a0+18:1=choice:0,1,2 \
    --mem @a0+19:1=0 --mem @a0+20:2=choice:0,1 --mem @a0+28:1=choice:0,1,2 --mem @a0+29:1=choice:0,1,3 \
    --stub-ret coll_ground_height=int --stub-ret tex_get=int --sig coll_ground_height=a0,a1,a2 --sig tex_get=a0,a1 \
    --follow coll_reset_dyn_tris,coll_add_dyn_tris,lvl_build_coll_tri,sqrtf --mem gDynTris:0x400=rand
# n1 = 0: the id is what coll_reset_dyn_tris leaves in v0 (&gDynTris)
