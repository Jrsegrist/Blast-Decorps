# cull_test_cells (cursors t3/s5 in-out; task data a1/a2/a3; block x/z/w/h/stride s0-s4, grid s6, scales s7/t8):
# callees stubbed, cull_rsp_test's visibility result from --stub-ret; w/h around 1 (single cell), odd/even
# halves, 0 and 0x7FFFFFFF (inputs stay where the asm's add/sub don't trap)
# Input range (wt-f1 investigation): the only caller, cull_walk_grid, loads x/z/w/h/stride with `lh`
# (s16), and w, h >= 1 (cull_grid_height_range counts them down with != 0). In that range none of the asm's
# trapping ops can overflow: z*stride + x < 2^31, x + (w >> 1) < 2^17, w - (w >> 1) >= 0. The overflow
# trap (exception 21) the C doesn't take needs 32-bit x/z/stride (z*stride + x or x + (w >> 1) past
# 2^31) or a negative w/h (w - (w >> 1) with srl'd w), neither reachable in game; so x/z/stride stay s16.

    --arg a1=int --arg a2=int --arg a3=int --arg s0=int:0:0x7FFF --arg s1=int:0:0x7FFF \
    --arg s2=choice:1*3,2,3,4,5,0x10,0x11,0,0x7FFFFFFF --arg s3=choice:1*3,2,3,4,7,0,0x7FFFFFFF \
    --arg s4=int:-0x8000:0x7FFF --arg s6=int --arg s7=int --arg t8=int
cull_test_cells: -n 100 --seed 1 --stub-ret cull_rsp_test=0 --arg t3=ptr:0x60 --arg s5=ptr:0x20 \
